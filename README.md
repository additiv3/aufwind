# Aufwind

Gleitschirm-Simulator fürs Handy. **Spielen:** https://additiv3.github.io/aufwind/

In Safari öffnen, dann *Teilen* → *Zum Home-Bildschirm*. Das Spiel läuft komplett im Browser,
lädt nichts nach und speichert den Spielstand nur auf dem eigenen Gerät.

Dieses Repository enthält nur die fertige Spieldatei. Sie wird automatisch veröffentlicht.
